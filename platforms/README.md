# Platforms

A future home for **verified** device/OS integration notes and reusable adapters.

**No universal adapter exists yet.** Nevermore's current software development targets Raven Prism through its separate private source repository; only simulator execution has been documented so far, not physical-device compatibility.

Add a device adapter only after confirming a supported public SDK/API and an actual usage need. Never imply that XR support means VR, AR or every model works interchangeably.
