# Experiences

Each folder represents **one themed smart-glasses experience**. Its README is the place to check availability and compatible devices.

- [Nevermore](nevermore/README.md) — Halloween. Existing private MVP candidate; **not yet exported or installable here**.
- [Christmas](christmas/README.md) — concept only.
- [St. Patrick's](st-patricks/README.md) — concept only.
- [Easter](easter/README.md) — concept only.

The [catalogue](../catalog/experiences.json) records these statuses for future discovery tooling. Create new experiences with [the template](../templates/experience/README.md).
