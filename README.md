# GlassPlay

**A little magic, right before your eyes.**

Seasonal surprises and interactive moments made for **AR smart glasses**. Explore an experience, discover what happens, and return to the real world whenever you want.

## Featured experience

[![Nevermore — Halloween for AR glasses](experiences/nevermore/cover.svg)](experiences/nevermore/README.md)

### [Nevermore →](experiences/nevermore/README.md)
**Halloween comes looking for you.**

An opt-in haunting with an animated raven, unexpected encounters and a midnight Trick or Treat.

**20 encounters** · **Offline voice trigger** · **Instant DISARM**

**Try the concept:** ARM → choose Trick or Treat → say **“Raven”** → DISARM anytime.

> **Preview status:** Tested in Raven Simulator. Physical Raven Prism and release media still require validation. **Not yet available to install from GlassPlay.**
