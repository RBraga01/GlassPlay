## Release behavior and limitations

This candidate preserves the 20 authored encounters, approved Midnight Host
sequence, Skull Warden, Veiled Wraith Bride gesture, Ocular Maw Chest and final
72-frame Raven Dive. ARM, Trick or Treat, local Raven voice recognition, DISARM,
overlap rejection, cancellation and retrigger behavior remain the upstream
implementation. The refreshed build changes provenance/credits, not gameplay.

The Windows/Simulator evidence is distinct from physical hardware validation.
Voice fixture tests do not certify live-human recognition accuracy. Full
application tests and decoding passed in the existing Windows SDK environment;
a fresh-machine installation has not been executed. Upstream environment and
test commands are preserved in the installation guide.
