## Release behavior and limitations

This candidate preserves the 20 authored encounters, approved Midnight Host
sequence, Skull Warden, Veiled Wraith Bride gesture, Ocular Maw Chest and final
72-frame Raven Dive. ARM, Trick or Treat, local Raven voice recognition, DISARM,
overlap rejection, cancellation and retrigger behavior remain the upstream
implementation. The refreshed build changes provenance/credits, not gameplay.

The Windows/Simulator evidence is distinct from physical hardware validation.
Voice fixture tests do not certify live-human recognition accuracy. Full
application tests and decoding passed in the existing Windows SDK environment;
a fresh-machine installation has not been executed. Upstream environment and
test commands are preserved in the installation guide.

## Approval handoff

The website introduction is complete. Changing published media requires a new
owner approval, a new bundle and manifest hash in `config/publication.json`, and
the same checked build. Keep application approval false and both candidate URLs
`null` until the application decision below.

For a later application release, record the code/art terms, applicable SDK
conditions and package scope separately. Update notices if needed, rebuild with
the existing packager if payloads change, verify the archive and refresh hashes
before attaching the exact approved package to its authorized destination. Only
that separate reviewed release decision enables public download links. Until
the respective scope is approved, retain the current withheld state and accurate
Windows/Simulator versus physical-device labels.
