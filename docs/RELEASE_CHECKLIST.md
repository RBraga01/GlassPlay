# GlassPlay release checklist

For an experience to be publicly **downloadable**, verify:

- [x] Curated source snapshot, with upstream provenance and no private Git history.
- [x] Current Nevermore Windows / Simulator candidate `v1.0.0-rc.2` built as a separate ZIP and hash file (private **draft**).
- [x] Candidate tested: 91 private tests; 80 application tests in the extracted package; 20-event audiovisual checks; persistence and exclusion scans.
- [x] Package excludes original Meshy source models, research archive, developer credentials and Raven Framework.
- [x] Meshy production sources: owner-attested paid-account generation; Guardian/Bride/Chest Meshy Community CC0 remixes recorded.
- [x] Code license MIT; Nevermore artwork/media All Rights Reserved; third-party notices included.
- [x] Raven Framework kept external and not relicensed; one dependency document (`RAVEN_FRAMEWORK.md`) to update.
- [ ] Raven publishes its official third-party Framework/deployment process (external).
- [ ] Prism app identity/entitlements from Raven (external).
- [ ] Obtain Raven Prism device evidence before promising physical-device support (DISPLAY / MIC / SPEAKER / PERF / THERMALS).
- [ ] Test the public-facing instructions on a clean machine.
- [ ] Approve the application download; only then set `install_url` / `release_url` and claim availability.

**Current GlassPlay status:** Nevermore `1.0.0-rc.2` is a release candidate shown on the live showcase; the package is a **private draft**, not a download.
